About

Frontend architecture that ships fast and stays fast.

I'm an SDE-2 on the frontend at Swivl, where I build the LLM-driven surfaces of an AI-powered work order platform: streaming chat, agentic workflows and tool-call rendering with the Vercel AI SDK and CopilotKit.

I own frontend architecture end to end. That means Next.js App Router and React Server Components, SSR and SSG, state with TanStack Query, Zustand and Redux Toolkit, design systems in shadcn/ui and Storybook, and the testing standards that keep it all honest.

Before Swivl I led frontend for an enterprise HR and Finance platform and rebuilt Resume.io's editor and template library. I mentor engineers, run technical interviews and care a lot about Core Web Vitals.
